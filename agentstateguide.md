When implementing refer to these prescriptive resources and follow the links and examples they share:

LangCache:   https://redis.io/docs/latest/develop/ai/context-engine/langcache/  
A semantic caching service that stores and reuses LLM responses for similar queries, reducing API costs and improving response latency.

Agent Memory:   https://redis.io/docs/latest/develop/ai/context-engine/agent-memory/   
A persistent memory service that maintains short-term session memory and long-term memory across agent interactions.

Context Retriever:    https://redis.io/docs/latest/develop/ai/context-engine/context-retriever/      
Turns your business data into structured tools that AI agents can safely and reliably use, defined once and reused across all agents.

Data integration: https://github.com/debezium/debezium-platformne/data-integration/
Syncs live data from your existing relational databases into dragonfly so agents always have access to fresh, accurate business data.
